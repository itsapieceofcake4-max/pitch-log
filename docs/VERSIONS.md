## app_22 — 22人シーンビューア（基本）

**役割**：ゴール前30秒シーンを「見る」ための土台アプリ。

- 22選手＋ボールの Plotly アニメーション再生（速度切替・コマ送り）
- xT ヒートマップ（Home青／Away赤／両方、初期＝両方）
- xT タイムライン（Home/Away MAX xT ＋ Ball xT）
- ゾーン別評価モード（ラインブレイクパス検知）
- 選手・ボールのホバーで **GridID / Zone_ID / xT** 表示
- 新シーン取り込みウィザード（フルCSV→シーン切出→変換）
- GSAエクスポート（フレーム範囲指定でCSV）
- 貢献度パネル（causal_scores_22.csv 連携）
- 📈 **試合全体モメンタム**（画面下部に埋め込み）

## app_23 — シーン＋VAEP/オフボール/守備（高度）

**役割**：app_22 の全機能 ＋ 因果・貢献度の深掘り分析。

- app_22 のシーン機能をすべて含む
- **VAEP 分析**：選手ごとの攻撃/守備 VAEP（dynamic_events から計算）
- **オフボールラン分析**：ラン由来 xthreat、ライン破り・裏抜け
- **守備ブレイクダウン**：stop_danger / reduce_danger / force_backward / beaten 系
- **Δ xT タイムライン**：時間ごとの xT 増加量
- ゾーン別 xT 分析（自陣／中盤／攻撃3rd）
- 📈 **試合全体モメンタム**（画面下部に埋め込み）

## app_24 — 試合全体モメンタム（俯瞰）

**役割**：90分を1枚で俯瞰し、流れ・ピンチ・チャンスを掴む。

- **モメンタムチャート** = xT added（ΔxT、一般指標・恣意的重みなし）
  - net（正負）／正のみ の切替、ローリング窓 1〜15分
  - 5分ローリング（局所）＋ 累積（全体ドリフト）
- **キーモーメント自動抽出**：⚽ゴール / 🔵チャンス(Homeシュート) / 🔴ピンチ(Awayシュート)
- **ボックス選択で区間抽出** → その区間の xT・件数・フェーズ明細・CSVダウンロード
- ズーム＆ダブルクリックで解除

## app_manual — ドキュメントビューア

- docs/ 配下の HTML（取説・カラムカタログ）を Streamlit で配信

| やりたいこと | 開くアプリ |
|---|---|
