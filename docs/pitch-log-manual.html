1. システム概要

Pitch Log は、SkillCorner トラッキングデータを使って サッカーの特定シーン（30秒程度）を可視化・評価するウェブアプリです。
ブラウザ上でアニメーション再生・xT ヒートマップ・プレーヤー貢献度をひとつの画面で確認できます。

v22 の主機能
xT
22選手のボール位置的脅威をアニメーション表示
v23 追加機能
VAEP
攻撃 / 守備 / オフボールを数値で選手評価
対象シーン
30秒
ゴール・ビルドアップ・プレッシング等、任意に切り出し可能
データソース
SkillCorner
10fps トラッキング + dynamic_events.csv

6. v23 の使い方

v23 は v22 のすべての機能に加えて、画面下部に 「📊 v23 プレーヤー貢献度分析」パネルが追加されます。

事前準備：貢献度を計算する

VAEP 分析を表示するには、選手貢献度データが必要です。
方法は2つあります。

方法 A ― アプリ内で計算（推奨）

1
サイドバー下部「🔬 v23 VAEP 分析」を開く
2
ファイルパスを確認・入力
  • dynamic_events CSV：SkillCorner の dynamic_events.csv
  • 選手貢献度 CSV：出力先（初期値のままでOK）
3
「🔄 貢献度を計算する」を展開 → 「⚙️ 貢献度を計算する」をクリック match_info.json のフレーム範囲で自動的にイベントを絞り込み、計算が完了したら画面が更新されます。

方法 B ― コマンドラインで計算

python xt_pipeline_23.py \
    --events 1925299_dynamic_events.csv \
    --match_info match_info.json \
    --output player_contributions_23.csv \
    --home_team_id 1802 \
    --away_team_id 871

実行後、player_contributions_23.csv が生成されます。アプリをリロードすると自動で読み込まれます。

💡 別のシーン（試合・時間帯）に切り替えた場合は、貢献度の再計算が必要です。
「⚙️ 貢献度を計算する」ボタンを再度押してください。

7. 指標の意味と読み方

xT（Expected Threat）

ピッチ上の各位置から得点につながる確率を 105×68 グリッドで表した指標。 ボールがある位置の「危険度」を示します。

指標意味高い = ?
Ball_xT ボール位置の xT（ポゼッション考慮済み） ゴールに近い危険な位置にボールがある
Home_MAX_xT Home 選手 11名の xT の最大値（フレームごと） Home チームで最も危険な位置にいる選手がいる
Away_MAX_xT Away 選手 11名の xT の最大値 Away チームで最も危険な位置にいる選手がいる
個人 xT その選手が立っている位置の xT その選手がゴールに近い危険なエリアにいる
💡 Ball_xT の変化でパスの価値がわかります。
例：0.01 → 0.05 に上昇した瞬間は、その直前のパスで +0.04 の価値が生まれたことを意味します。 xT タイムラインで「急上昇する点」がチャンス創出のタイミングです。

VAEP（Value of Actions by Estimating Probabilities）

各アクションが「得点確率」と「失点確率」をどう変化させたかを計算する指標。 ゴールやシュートに直結しないプレーも評価できます。 

VAEP = Δ P(得点) − Δ P(失点)
     = (xshot_end − xshot_start) − (xloss_end − xloss_start)
指標計算元対象プラス = ?
vaep_attack on_ball_engagement イベント ボール保持者（攻撃側） プレッシャー下でも攻撃価値を維持・向上
vaep_defend on_ball_engagement イベント エンゲージした守備側 相手の攻撃を効果的に阻止
off_ball_xthreat off_ball_run イベント ランした選手 危険なスペースへのランで味方をサポート
vaep_total 上記3つの合算 全選手 シーン全体への総合貢献が高い
⚠️ VAEP は「on_ball_engagement（守備エンゲージメント）」イベントから計算されます。
パスを出す / 受ける場面でなく、守備側が接触を試みた場面が対象です。
そのため、ボール保持者のパス精度等は 直接は評価されません。

9. よくある質問

Q. v22 と v23 は同時に使えますか？

はい。Streamlit Cloud では別々のデプロイとして登録し、異なる URL を使います。 ローカルでは app_22.py と app_23.py を別ターミナルで起動してください。

Q. 別の試合のデータでも使えますか？

はい。シーン CSV と dynamic_events.csv を対象試合のものに入れ替え、 match_info.json の home_team_id / away_team_id を 対象チームの SkillCorner ID に変更してください。

Q. 「貢献度を計算する」を押したら画面が変わらない

以下を確認してください：

  1. dynamic_events.csv のパスが正しいか
  2. match_info.json が存在し、goal_frame_raw と window_frames が含まれているか
  3. Team ID が対象試合のものか（Brisbane=1802, Perth=871）
  4. フレーム範囲を「手動指定」に切り替えて試す

Q. xT と VAEP はどう使い分けますか？

xTVAEP
向いている用途「どこに誰がいたか」の把握「誰がどう貢献したか」の定量評価
ゴール以外の評価位置情報のみパス・守備・オフボールも評価
アニメーション連動✅ リアルタイム表示シーン単位の集計値

推奨: ピッチアニメで戦術を確認（xT）→ 誰が鍵だったかを数値で検証（VAEP）の順で使うと効果的です。

Q. 選手番号と VAEP はどう対応していますか？

現在、ピッチアニメの選手番号（Home_P1〜P11）と VAEP の選手名（J. Risdon 等）は 自動で紐付いていません。
SkillCorner の player_id → トラッキングスロット番号のマッピングデータが必要です。 将来バージョンで対応予定です。
